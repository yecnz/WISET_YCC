# SugarFit Lab

맛 만족도와 섭취 안전성을 동시에 고려한 AI 기반 저당 음료 배합 최적화 시스템 MVP입니다.

## 실행 방법

`index.html`을 브라우저로 열면 바로 실행됩니다. 별도 설치가 필요 없습니다.

## 사용자 흐름 (연구자·식품 회사용 워크플로)

1. **배합 탐색 (4단계 위저드):** 제품 정의(음료·제공량·목표 당도) → 타깃 조건(체중·위장·혈당, 페르소나 프리셋 3종) → 원료·제약(보유 원료 선택, 1잔 원가 상한, 천연 유래만 라벨링 조건) → 탐색 실행
2. **자동 그리드 탐색:** 선택 원료의 단독·2종·3종 조합을 비중 10% 단위로 전수 생성(5종 기준 455개) → 안전성 엔진(하드 캡·GI 필터)과 원가·라벨링 제약으로 필터링
3. **탐색 결과:** 추천 1 + 대안 2(구성 거리 0.15 이상 다양성 보장) + 근거 + 계산 과정 펼쳐보기 + 민감도 체크(체중 ±10kg·당도 ±1단계에서 추천 유지 여부) + 레이더·산점도·랭킹 + 설탕 대조군 비교
4. **실험 루프:** 추천 카드에서 실험 시트(CSV, 칭량값·제조 순서·블라인드 코드) 내보내기 → 배치 등록 → 평가 입력에서 블라인드 코드로 관능평가 → 데이터가 쌓이면 예측이 자동 갱신 (능동학습 루프)

## 엔진 구조

- **안전성 엔진(확정적):** 성분별 하드 캡 = min(체중 × ADI(또는 내약 상한) × 1잔 배분율 50%, 맛 상한선). 위장 민감도(예민 ×0.5 / 보통 ×0.8)로 당알코올 상한 하향, 혈당 관리 시 GI 높은 성분(말티톨) 제외, 원가 상한·천연 유래 제약 추가 필터.
- **추천 엔진(v1.5, 규칙 + 거리 가중 예측):** 실측 배합은 관능 평가 평균을 그대로 사용하고, 미실험 배합은 구성 거리 기반 가우시안 가중 보간으로 예측(실측/예측 배지로 구분). 종합점수 가중치는 전체 기호도 30%·설탕 유사도 20%·단맛 15%·바디감 15%·향미 균형 10%·끝맛 안정성 10%. 최종 점수 = 종합점수 + 개인 적합도 보정 + 안전 여유 가점.

## 데이터 관리

- **룰 테이블 화면:** 출처·버전·검증 전 배지 표시. 맛 상한선·단가는 자사 기준으로 수정 가능(감미도·ADI·GI는 안전 직결 값이라 코드에서만 갱신).
- **프로젝트 JSON 내보내기/가져오기:** 로그인 없이 파일 기반으로 보관·공유. 관능 데이터 CSV 내보내기(UTF-8 BOM, 엑셀 호환).

## 범위 제외

로그인, 커뮤니티, v2(회귀/RSM)·v3(베이지안 최적화) 알고리즘 실구현은 범위에서 제외했습니다. 추천 엔진의 예측 함수만 교체하면 v2/v3로 확장되는 구조입니다.

## 주의

룰 테이블의 내약 상한·맛 상한선·단가 일부는 발표용 mock 수치이며 화면에 "검증 전"으로 표기됩니다. 제출 전 식약처, FDA, EFSA 등 원자료 기준으로 재확인해야 합니다. 안전성 표현은 진단이 아닌 "알려진 섭취 상한 기준의 과량 제어"로 한정합니다.
