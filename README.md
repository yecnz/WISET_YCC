# SugarFit Lab

맛 만족도와 섭취 안전성을 동시에 고려한 AI 기반 저당 음료 배합 최적화 시스템 MVP입니다.

## 실행 방법

`index.html`을 브라우저로 열면 바로 실행됩니다. 별도 설치가 필요 없습니다.

## 주요 기능

- 저당 음료 배합 후보 관리
- 체중, 위장 민감도, 음료 종류, 목표 당도 기반 타깃 조건 입력
- 알룰로스, 스테비아, 에리스리톨 등 대체당 조합 관리
- 대체당별 프로젝트 기준 섭취 상한을 활용한 안전성 엔진
- 참여자 그룹별 관능평가 입력
- 만족도, 재구매 의향, 당 함량, 칼로리, 안전 여유도 기반 추천 점수 계산
- 안전 후보 안에서 다음 실험 배합 추천
- 안전 여유도 대비 만족도 차트
- CSV 데이터 내보내기

## 발표 포인트

이 앱은 단순 레시피 기록장이 아니라, 안전성 엔진과 추천 엔진을 분리한 연구 자동화 프로토타입입니다. 먼저 체중과 위장 민감도를 바탕으로 대체당 과량 후보를 차단하고, 통과한 후보 안에서 관능평가 데이터를 기반으로 다음 실험 배합을 추천합니다. 1차 타깃은 식품 연구팀과 창업자이며, 이후 소비자용 추천 서비스와 기업용 신제품 개발 솔루션으로 확장할 수 있습니다.

## 주의

현재 안전성 수치는 발표용 프로토타입의 프로젝트 기준입니다. 제출 전 식약처, FDA, EFSA 등 원자료 기준으로 성분별 ADI와 표현을 재확인해야 합니다.
